# Project-Scoped Rules for Antigravity

## Content Creation Workflow (Blog & News)
- **Do NOT automatically execute `npm run local-build` or `local-build` checks when the task is simply to write, import, or update a blog post or news article.**
- Only run `local-build` validation when specifically requested by the user or when introducing core system changes (like modifying Astro templates, configuration files, or routing/rewrites).
